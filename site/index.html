RGenomicsETL DuckDB extensions

Signed builds of RGenomicsETL extensions, served as DuckDB external extension repositories (DuckDB 2.0 and later).

Use

Register a channel once:

SET allow_extension_repositories = 'allowed';
CREATE EXTENSION REPOSITORY rgenomicsetl
  WITH PREFIX 'https://rgenomicsetl.github.io/duckdb-extensions/stable';
INSTALL AND LOAD duckhts FROM rgenomicsetl;

Check that the fingerprint DuckDB prints matches the one below before installing. Use the dev prefix for builds from each project's main branch. A specific build can be installed with FORCE INSTALL duckhts VERSION '…' FROM rgenomicsetl, loaded in a fresh database instance.
